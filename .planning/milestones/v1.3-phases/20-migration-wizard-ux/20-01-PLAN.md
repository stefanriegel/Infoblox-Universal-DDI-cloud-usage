<task type="auto">

  <files>src/cloud_usage/dashboard/templates/partials/nios/step1_upload.html</files>
  <action>
    After the `<h3>Step 2: Assign Members</h3>` heading and before the `<figure>` wrapping the member table:

    1. Add a flex container `<div style="display: flex; align-items: center; gap: 1rem; margin-bottom: 0.5rem;">` containing:
       - `<button type="button" onclick="...">Select All</button>` — the onclick iterates all `input[name=niosx_member]` checkboxes, sets `.checked = true`, and dispatches `new Event('change', {bubbles: true})` on each.
       - `<button type="button" onclick="...">Clear All</button>` — same pattern but sets `.checked = false`.
       - `<span id="nios-group-counter" style="font-size: 0.9em; color: var(--pico-muted-color, #666);">` initialised with server-rendered values: `NIOS: {{ members|length }} member{{ 's' if members|length != 1 else '' }} | NIOSX: 0 members`

    2. After the closing `</figure>` tag (before `<button type="submit">Run Analysis</button>`), add an inline `<script>` block with an IIFE:
       ```javascript
       (function() {
         var counter = document.getElementById('nios-group-counter');
         var total = {{ members|length }};
         function updateCounter() {
           var niosx = document.querySelectorAll('input[name=niosx_member]:checked').length;
           var nios = total - niosx;
           counter.textContent = 'NIOS: ' + nios + ' member' + (nios !== 1 ? 's' : '')
             + ' | NIOSX: ' + niosx + ' member' + (niosx !== 1 ? 's' : '');
         }
         document.querySelectorAll('input[name=niosx_member]').forEach(function(cb) {
           cb.addEventListener('change', updateCounter);
         });
       })();
       ```
       The IIFE scopes all variables; no global pollution.

    Use `type="button"` on both batch buttons to prevent form submission.
    Dispatch `change` events from batch buttons so the counter updates when Select All / Clear All is clicked.
  </action>
