  member_hostname="__grid__"). Per-member MemberCounts.active_ip_count = per-member
  lease-derived IPs only. This resolves the open question from RESEARCH.md.

    count_objects() algorithm:
    1. global_ip_set: set[str] = set()  # single global set for Active IP deduplication
    2. per_member: dict[str, _MemberAcc] = defaultdict(_MemberAcc)
    3. grid_ddi = 0  # DDI count for grid-level objects
    4. grid_lease_count = 0  # total raw lease count across all members
    5. For each obj in objects:
       a. DDI counting:
          - If family == HOST_OBJECT: determine expansion (+2 or +3)
            check raw_attrs.get("aliases", "").strip() — if non-empty, +3 else +2
          - Elif family in _DDI_FAMILIES (non-HOST_OBJECT): +1
          - If member_hostname is None: add to grid_ddi
          - Else: per_member[member_hostname].ddi_count += delta
       b. Lease counting (binding_state filter):
          - If family == LEASE:
            state = raw_attrs.get("binding_state", "")
            If state in set(config.lease_states):
              ip = raw_attrs.get("ip_address", "").strip()
              if ip: global_ip_set.add(ip)
              if member_hostname: per_member[member_hostname].lease_ip_set.add(ip)
            # Track raw lease rows (regardless of binding_state filter):
            grid_lease_count += 1  # always count raw lease rows
            if member_hostname: per_member[member_hostname].lease_count += 1
       c. Fixed address / host address IP:
          - If family in (FIXED_ADDRESS, HOST_ADDRESS):
            ip = raw_attrs.get("ip_address", "").strip()
            if ip: global_ip_set.add(ip)
       d. Network reservation IPs:
          - If family == NETWORK:
            cidr = raw_attrs.get("cidr", "").strip()
            if cidr:
              try:
                net = ipaddress.IPv4Network(cidr, strict=False)
                global_ip_set.add(str(net.network_address))
                global_ip_set.add(str(net.broadcast_address))
              except ValueError: pass  # malformed CIDR — skip silently
    6. Build result:
       member_counts = [
           MemberCounts(
               member_hostname=hostname,
               ddi_count=acc.ddi_count,
               active_ip_count=len(acc.lease_ip_set),
               lease_count=acc.lease_count,
               asset_count=0,
           )
           for hostname, acc in per_member.items()
       ]
       grid_counts = MemberCounts(
           member_hostname="__grid__",
           ddi_count=grid_ddi,
           active_ip_count=len(global_ip_set),
           lease_count=grid_lease_count,
           asset_count=0,
       )
       return CountResult(member_counts=member_counts, grid_counts=grid_counts)

    IMPORTANT NOTE on lease_count:
    - raw_attrs.get("binding_state") exists on ALL LEASE objects regardless of state
    - lease_count (raw rows) = count of ALL LEASE objects for that member
    - active_ip_count = count of UNIQUE IPs from state-filtered leases for that member
    - These are separate metrics: lease_count is "how many DHCP lease records",
      active_ip_count is "how many unique active IPs"

    IMPORTANT NOTE on HOST_OBJECT alias detection:
    The raw_attrs key to use for detecting CNAME presence in HOST_OBJECT may be "aliases"
    (a comma-separated list of alias hostnames) or a different key. Since the ZF reference
    backup has 129,930 HOST_OBJECT entries (from _families.py), the exact key should be
    confirmed from RESEARCH.md. RESEARCH.md states: "check for 'aliases' key or 'has_cname'
    key in raw_attrs — if present and non-empty, +3; otherwise +2."
    Use: `if raw_attrs.get("aliases", "").strip(): delta = 3 else: delta = 2`
    This is safe: if the key is absent or empty, defaults to +2 (A+PTR only).
