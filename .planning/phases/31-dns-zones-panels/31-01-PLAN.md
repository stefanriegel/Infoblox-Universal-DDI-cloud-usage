DNS record details fields (confirmed from provider collector source):
- route53-record: details["zone_id"] = zone_id, details["zone_name"] = zone_name (FQDN)
- azure-dns-record: details["zone_name"] = zone.name
- azure-private-dns-record: details["zone_name"] = zone.name
- gcp-dns-record: details["zone_name"] = internal zone name (NOT FQDN); FQDN is on zone resource's .name (dns_name)

Cloud zone resources have details["record_count"] (integer):
- route53-zone: details["record_count"] from Route53 ResourceRecordSetCount
- azure-dns-zone: details["record_count"] from number_of_record_sets
- azure-private-dns-zone: details["record_count"] from number_of_record_sets
- gcp-dns-zone: NO record_count in details — must count gcp-dns-record resources separately

AD DNS record resource_id format: "ad:dns-record:{zone}|{owner}|{type}|{data}"
