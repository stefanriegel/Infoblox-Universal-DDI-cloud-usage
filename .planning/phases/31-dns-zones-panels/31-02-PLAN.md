Cloud DNS zone-to-record linkage (confirmed from source):

route53-zone: details = {"zone_type": ..., "record_count": int}
route53-record: details = {"zone_id": str, "zone_name": str (FQDN), "record_type": str, ...}
  --> Use: resource_type=="route53-zone" zone has details["record_count"] (from Route53 ResourceRecordSetCount)
  --> Prefer: use details["record_count"] on zone resource directly for AWS

azure-dns-zone: details = {"resource_group": str, "zone_type": "public", "record_count": int}
azure-private-dns-zone: details = {"resource_group": str, "zone_type": "private", "record_count": int}
  --> Both have details["record_count"] from number_of_record_sets

gcp-dns-zone: details = {"zone_name": str (internal name), "dns_name": str (FQDN), "visibility": str}
  --> NO record_count in details — must count gcp-dns-record resources per zone
gcp-dns-record: details = {"record_type": str, "ttl": int, "zone_name": str (internal name)}
  --> Match record details["zone_name"] to zone details["zone_name"] to get FQDN from zone.name

Strategy for DNS-01 (avoids all join complexity):
1. Collect all zone resources with details["record_count"] → (zone.name, count) — covers AWS + Azure
2. For GCP zones (resource_type=="gcp-dns-zone"), count gcp-dns-record resources by matching details["zone_name"]
3. Sort all (zone_name, count) descending, take top 5

    ```python
    def _compute_top_cloud_dns_zones(resources: list) -> list[tuple[str, int]]:
        """Compute Top 5 DNS zones by record count from cloud resources.

        AWS and Azure zones carry details["record_count"] directly.
        GCP zones have no record_count — count gcp-dns-record resources by zone.

        Returns:
            List of (zone_name, count) tuples, max 5, sorted descending by count.
        """
        zone_counts: dict[str, int] = {}

        # AWS and Azure: use record_count from zone resource details
        ZONE_TYPES_WITH_COUNT = {"route53-zone", "azure-dns-zone", "azure-private-dns-zone"}
        for r in resources:
            if r.resource_type in ZONE_TYPES_WITH_COUNT:
                count = r.details.get("record_count", 0) or 0
                if r.name:
                    zone_counts[r.name] = zone_counts.get(r.name, 0) + count

        # GCP: build zone name → FQDN map, then count records
        gcp_zone_internal_to_fqdn: dict[str, str] = {}
        for r in resources:
            if r.resource_type == "gcp-dns-zone":
                internal = r.details.get("zone_name", "")
                fqdn = r.name  # dns_name on the zone object
                if internal and fqdn:
                    gcp_zone_internal_to_fqdn[internal] = fqdn

        gcp_counts: dict[str, int] = {}
        for r in resources:
            if r.resource_type == "gcp-dns-record":
                internal = r.details.get("zone_name", "")
                fqdn = gcp_zone_internal_to_fqdn.get(internal, "")
                if fqdn:
                    gcp_counts[fqdn] = gcp_counts.get(fqdn, 0) + 1

        zone_counts.update(gcp_counts)

        # Sort descending, take top 5
        return sorted(zone_counts.items(), key=lambda x: x[1], reverse=True)[:5]
    ```
