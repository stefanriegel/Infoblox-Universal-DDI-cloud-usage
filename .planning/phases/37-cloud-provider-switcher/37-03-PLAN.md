base.html nav block to insert (between breadcrumb nav and main):
```html
{% if calc_theme == 'calc-cloud' %}
<nav class="provider-selector" aria-label="Cloud provider">
  <div class="container">
    <span class="provider-selector-label">Provider:</span>
    {% for p_key, p_label in [('aws', 'AWS'), ('azure', 'Azure'), ('gcp', 'GCP')] %}
    <button class="provider-pill{% if active_provider == p_key %} active{% endif %}"
            hx-get="/cloud/{{ p_key }}/tab/progress"
            hx-target="#tab-container"
            hx-push-url="false">{{ p_label }}</button>
    {% endfor %}
  </div>
</nav>
{% endif %}
```

base.html #tab-container hx-get to update (conditional):
```html
<div id="tab-container"
     hx-get="{% if calc_theme == 'calc-cloud' %}/cloud/{{ active_provider }}/tab/{{ active_tab }}{% else %}/tab/{{ active_tab }}{% endif %}"
     hx-trigger="load"
     hx-target="#tab-container">
  <p>Loading...</p>
</div>
```

Note: active_provider defaults to "aws" if not set. This template change is backward-compatible with NIOS and AD calculators because the `{% else %}` branch uses the existing `/tab/{{ active_tab }}` path.
