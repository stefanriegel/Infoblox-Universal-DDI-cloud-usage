**Bug 1+2: _enumerate_accounts GCP path (lines 169-182):**
- Change `enumerate_gcp_projects(credentials, adc_project)` to `enumerate_gcp_projects(credentials, adc_project, None, None, None, None)` — all 6 positional args required.

**Bug 3: _build_discovery_providers GCP path (lines 452-456):**
- Change `enumerate_gcp_projects(credentials, adc_project, include_patterns=include, exclude_patterns=exclude)` to `enumerate_gcp_projects(credentials, adc_project, None, None, include, exclude)` — add the missing `project=None` and `org_id=None` positional args.

**Bug 4: _enumerate_accounts Azure path (lines 158-164):**
- Change `"id": s.get("subscription_id", s.get("id", ""))` to `"id": s.get("id", "")` — the `subscription_id` key does not exist in `list_subscriptions()` return dicts.
- Change `"display_name": s.get("display_name", s.get("subscription_id", ""))` to `"display_name": s.get("display_name", s.get("id", ""))` — fallback to `id` instead of nonexistent `subscription_id`.

**AWS audit:** No bugs found in AWS path — `list_accounts()` returns strings, iteration is correct, `_build_discovery_providers` call is correct.

**Error UX for _enumerate_accounts:**
- Change return type from `dict[str, list[dict]]` to `dict[str, dict]` where each value is `{"accounts": [...], "error": str | None}`.
- In each provider's try/except block: on success, set `{"accounts": [...], "error": None}`; on exception, set `{"accounts": [], "error": str(exc)}`.
- Apply this pattern to ALL three providers (AWS, Azure, GCP).
- Update the docstring to document the new return structure.

**Update callers of _enumerate_accounts:**
- `wizard_accounts` route: update the `accounts` variable passed to template to use the new structure (template expects `accounts[provider]` to be the result dict with `accounts` and `error` keys).
- `wizard_filter_accounts` route: update `provider_accounts = accounts.get(provider, [])` to `provider_accounts = accounts.get(provider, {}).get("accounts", [])` since the return structure changed.
