Session building:
```python
def _build_session(self, server: str):
    winrm_module = importlib.import_module("winrm")
    endpoint = f"{'https' if use_ssl else 'http'}://{server}:{port}/wsman"
    kwargs = {"transport": auth_mode, "server_cert_validation": cert_validation}
    if username and password:
        kwargs["auth"] = (username, password)
    kwargs["operation_timeout_sec"] = timeout
    kwargs["read_timeout_sec"] = timeout + 5
    return winrm_module.Session(endpoint, **kwargs)
```

PS execution with retry:
```python
def _run_ps_text(self, session, script: str) -> str:
    for attempt in range(1, max_retries + 1):
        response = session.run_ps(script)
        if response.status_code != 0:
            raise RuntimeError(stderr or stdout or "WinRM command failed")
        return decode(response.std_out)
        # on exception: sleep backoff_base * 2^(attempt-1), then retry

def _run_ps_json(self, session, script: str) -> object:
    text = _run_ps_text(...)
    return json.loads(text)  # raises RuntimeError on bad JSON
```

DNS collection PS scripts:
```powershell
# Zones:
Get-DnsServerZone -ErrorAction Stop | Select-Object @{Name='ZoneName';Expression={$_.ZoneName}} | ConvertTo-Json -Compress

# Records per zone:
Get-DnsServerResourceRecord -ZoneName '{zone}' -ErrorAction Stop |
  Select-Object @{Name='HostName';Expression={$_.HostName}},
                @{Name='RecordType';Expression={($_.RecordType).ToString()}},
                @{Name='RecordData';Expression={($_.RecordData | ConvertTo-Json -Compress -Depth 6)}} |
  ConvertTo-Json -Compress -Depth 8
```
Dedup key: `{zone_name}|{owner}|{record_type}|{record_data_json_normalized}`
A/AAAA record IP extracted from RecordData dict (IPv4Address or IPv6Address field).

DHCP collection PS scripts:
```powershell
Get-DhcpServerv4Scope -ErrorAction Stop | Select-Object @{Name='ScopeId';Expression={$_.ScopeId.IPAddressToString}} | ConvertTo-Json -Compress
Get-DhcpServerv4Lease -ScopeId '{scope}' -ErrorAction Stop | Select-Object @{Name='IPAddress';Expression={$_.IPAddress.IPAddressToString}} | ConvertTo-Json -Compress
Get-DhcpServerv4Reservation -ScopeId '{scope}' -ErrorAction Stop | Select-Object @{Name='IPAddress';Expression={$_.IPAddress.IPAddressToString}} | ConvertTo-Json -Compress
```
Lease dedup key: `{scope_id}|{ip}`. Reservation dedup key: same pattern.

User collection PS script:
```powershell
Get-ADUser -Filter * -ErrorAction Stop |
  Select-Object @{Name='SID';Expression={if ($_.SID) { $_.SID.Value } else { $null }}},
                @{Name='UserPrincipalName';Expression={$_.UserPrincipalName}},
                @{Name='SamAccountName';Expression={$_.SamAccountName}} |
  ConvertTo-Json -Compress -Depth 6
```
User key priority: sid: → upn: → sam:

    _build_session(self, server: str): lazy winrm import → build endpoint URL → construct kwargs dict (transport, server_cert_validation, auth if credentials) → set operation_timeout_sec and read_timeout_sec → winrm.Session(endpoint, **kwargs). Catch TypeError (old winrm API) and retry without timeout kwargs.

    _collect_dns(self, session) -> dict:
      - Run Get-DnsServerZone PS → parse zones list
      - For each zone: run Get-DnsServerResourceRecord PS → parse records
      - Dedup key: f"{zone_name}|{owner}|{record_type}|{record_data_json_normalized}"
      - Only SUPPORTED_DNS_RECORD_TYPES records counted
      - Extract IP from A record RecordData["IPv4Address"], AAAA record RecordData["IPv6Address"]
      - Return: {"zone_keys": set, "supported_record_entries": set[tuple[key, rtype]], "ip_addresses": list[str], "unsupported_record_keys": set}

    _collect_dhcp(self, session) -> dict:
      - Run Get-DhcpServerv4Scope → parse scopes
      - Per scope: Get-DhcpServerv4Lease + Get-DhcpServerv4Reservation
      - Dedup keys: f"{scope_id}|{ip}"
      - Return: {"scope_keys": set, "lease_keys": set, "reservation_keys": set}

    _collect_users(self, session) -> dict:
      - Run Get-ADUser -Filter * PS → parse users
      - User key: "sid:{sid}" if SID else "upn:{upn}" if UPN else "sam:{sam}"
      - Skip if no key derivable
      - Return: {"user_keys": set[str], "sid_map": dict[key, sid_str]}

    _discover_domains(self, session) -> list[str]: run Get-ADForest PS → parse domain list → normalize.
    _discover_dns_servers(self, session, domain: str) -> list[str]: Get-ADDomainController per domain → HostName list → normalize.

    _resolve_targets(self, servers: list[str], options: AdOptions) -> dict[str, set[str]]:
      - If not autodiscover: for each server add services from options.services
      - If autodiscover: build session on options.discovery_server; discover domains; per domain discover DCs; add dns+user services to each DC; discover DHCP servers for dhcp service
      - Raise ValueError if no targets resolved for a requested service
      - Return: dict[server_hostname, set_of_services]

    _collect_server(self, server: str, services: set[str], options: AdOptions) -> dict:
      - Build session
      - Collect each requested service; catch exceptions per service → log warning, record as None (service skipped)
      - Return: {"server": server, "status": "ok"|"error", "dns": {...}|None, "dhcp": {...}|None, "user": {...}|None}

    collect_all(self, options: AdOptions) -> tuple[list[dict], list[str]]:
      - _resolve_targets → targets dict
      - For each server: call _collect_server; catch server-level exception → append error string, continue
      - Return (server_results_list, errors_list)
      - NOTE: Returns raw dicts; conversion to CloudResource is done in the runner (29-03)
