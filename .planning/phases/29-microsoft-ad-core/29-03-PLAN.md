  "ad-dns-zone"   → DDI, ip_addresses=[]
  "ad-dns-record" → DDI, ip_addresses=[ip] for A/AAAA (extracted from record data), else []
  "ad-dhcp-scope" → DDI, ip_addresses=[]
  "ad-dhcp-ip"    → Asset (has ip_addresses=[lease_or_reservation_ip]) — NOT in DDI_TYPES
  "ad-user"       → Asset via sentinel ip_addresses=["0.0.0.0"]; details has sid, domain

Dedup across DCs: aggregate set operations across all server_results before converting to CloudResources.
  - Zone dedup: union of zone_keys sets across all servers sharing same domain
  - Record dedup: union of supported_record_entries sets (tuple keys ensure dedup)
  - DHCP: union of scope/lease/reservation key sets per domain
  - User: union of user_keys across ALL domains (global SID dedup)

    Implement _aggregate_results(server_results: list[dict]) -> dict:
      Per-domain aggregation:
      - dns: union zone_keys, union supported_record_entries (set of tuples), union ip_addresses lists, union unsupported_record_keys
      - dhcp: union scope_keys, lease_keys, reservation_keys
      - user: global union of user_keys and sid_map across ALL domains
      Return: {"domains": {domain: {"dns": ..., "dhcp": ...}}, "users": {"user_keys": set, "sid_map": dict}}

    Implement _to_cloud_resources(aggregated: dict, options: AdOptions) -> list[CloudResource]:
      For each domain in aggregated["domains"]:
        account_id = domain
        region = domain

        DNS zones (if "dns" in options.services):
          - For each zone_name in dns["zone_keys"]:
            yield CloudResource(resource_id=f"ad:dns-zone:{domain}:{zone_name}",
                                resource_type="ad-dns-zone", provider="ad",
                                account_id=account_id, region=region,
                                name=zone_name, ip_addresses=[],
                                details={"zone": zone_name, "domain": domain})

        DNS records (if "dns" in options.services):
          - For each (record_key, record_type) in dns["supported_record_entries"]:
            Extract ip from record_key if record_type in ("A", "AAAA") — parse last segment of zone|owner|type|data key
            Actually: ip_addresses for A/AAAA come from dns["ip_addresses"] which is a list (not per-record).
            Better approach: store (record_key, record_type, ip_str_or_empty) in supported_record_entries (3-tuple).
            NOTE: Coordinate with 29-02 collector — collector should return set[tuple[key, rtype, ip_str]] where ip_str is "" for non-A/AAAA types. If 29-02-SUMMARY confirms different shape, adapt here.
            yield CloudResource(resource_id=f"ad:dns-record:{record_key}",
                                resource_type="ad-dns-record", provider="ad",
                                account_id=account_id, region=region,
                                name=record_key.split("|")[1],  # owner field
                                ip_addresses=[ip_str] if ip_str else [],
                                details={"record_key": record_key, "record_type": record_type, "domain": domain})

        DHCP scopes (if "dhcp" in options.services):
          - For each scope_id in dhcp["scope_keys"]:
            yield CloudResource(resource_id=f"ad:dhcp-scope:{domain}:{scope_id}",
                                resource_type="ad-dhcp-scope", provider="ad",
                                account_id=account_id, region=region,
                                name=scope_id, ip_addresses=[],
                                details={"scope_id": scope_id, "domain": domain})

        DHCP IPs — leases (if "dhcp" in options.services):
          - For each lease_key in dhcp["lease_keys"]:
            scope_id, ip = lease_key.split("|", 1)
            yield CloudResource(resource_id=f"ad:dhcp-lease:{domain}:{lease_key}",
                                resource_type="ad-dhcp-ip", provider="ad",
                                account_id=account_id, region=region,
                                name=ip, ip_addresses=[ip],
                                details={"scope_id": scope_id, "lease_type": "lease", "domain": domain})

        DHCP IPs — reservations (if "dhcp" in options.services):
          - Same pattern as leases with resource_id prefix "ad:dhcp-reservation:" and lease_type="reservation"

      Users (if "user" in options.services) — global, not per-domain:
        global_users = aggregated["users"]
        For each user_key in global_users["user_keys"]:
          sid = global_users["sid_map"].get(user_key, "")
          domain_hint = user_key.split(":")[0] if ":" in user_key else "global"
          yield CloudResource(resource_id=f"ad:user:{user_key}",
                              resource_type="ad-user", provider="ad",
                              account_id=domain_hint, region=domain_hint,
                              name=user_key, ip_addresses=["0.0.0.0"],
                              details={"user_key": user_key, "sid": sid})

    Implement run_ad_analysis(options: AdOptions, output_path: str) -> str:
      collector = MicrosoftAdCollector()
      server_results, errors = collector.collect_all(options)
      aggregated = _aggregate_results(server_results)
      resources = list(_to_cloud_resources(aggregated, options))
      categorize_resources(resources)
      written = write_xlsx_report(
          filepath=output_path,
          resources=resources,
          account_summaries={},
          errors=errors,
          provider="ad",
      )
      return written
