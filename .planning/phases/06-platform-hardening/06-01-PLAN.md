Create `src/cloud_usage/preflight.py` with:

1. `check_platform() -> dict` function that returns a dict with:
   - `python_ok`: bool — `sys.version_info >= (3, 10)`
   - `python_version`: str — formatted version string
   - `system`: str — `platform.system()` result ("Windows", "Darwin", "Linux")
   - `is_wsl`: bool — `sys.platform == "linux" and "microsoft" in platform.release().lower()`
   - `long_path_enabled`: bool — True on non-Windows; on Windows, read `HKLM\SYSTEM\CurrentControlSet\Control\FileSystem\LongPathsEnabled` via `winreg` (guarded import with try/except OSError returning False)
   - `execution_policy`: str | None — None on non-Windows; on Windows, run `powershell -Command Get-ExecutionPolicy` via subprocess with 5s timeout (return None on any exception)
   - `ansi_capable`: bool — on Windows check `sys.stderr.isatty()` AND (`os.environ.get("WT_SESSION")` or `os.environ.get("TERM")`); on non-Windows check `sys.stderr.isatty()`
   - `cli_aws`: bool — `shutil.which("aws") is not None`
   - `cli_az`: bool — `shutil.which("az") is not None`
   - `cli_gcloud`: bool — `shutil.which("gcloud") is not None`

2. `print_preflight_warnings(results: dict) -> None` function that:
   - If `python_ok` is False: print to stderr "Python 3.10+ required (found {version})" and return early (this is the only hard error)
   - If `system` is "Windows" and `long_path_enabled` is False: warn "Windows long path support is disabled. Enable: New-ItemProperty -Path 'HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem' -Name 'LongPathsEnabled' -Value 1 -PropertyType DWORD -Force"
   - If `execution_policy` is "Restricted" or "Undefined": warn "PowerShell ExecutionPolicy is '{policy}'. Set-ExecutionPolicy RemoteSigned -Scope CurrentUser"
   - If `ansi_capable` is False AND `system` is "Windows": warn "Terminal does not support ANSI colors — output may contain escape codes"
   - Print summary: "Platform: {system}{' (WSL)' if is_wsl else ''} | Python {version} | CLIs: aws={'yes' if cli_aws else 'no'}, az={'yes' if cli_az else 'no'}, gcloud={'yes' if cli_gcloud else 'no'}"
   - Warnings print to `sys.stderr` and never block execution (never sys.exit) except Python version < 3.10

Use `from __future__ import annotations` at the top. All private helpers (`_check_long_path_registry`, `_check_ansi`, `_check_execution_policy`) are module-level functions with leading underscore.

**Wire into CLI:** In `src/cloud_usage/cli.py`, add `from cloud_usage.preflight import check_platform, print_preflight_warnings` import at top. In `main()`, immediately after `args = parse_args(argv)` and before the web dashboard check, add:

**Fix SIGTERM guard:** In `src/cloud_usage/discovery/shutdown.py`, add `import sys` to the imports. In `GracefulShutdown.__init__`, change:
```python
signal.signal(signal.SIGINT, self._handler)
signal.signal(signal.SIGTERM, self._handler)
```
to:
```python
signal.signal(signal.SIGINT, self._handler)
if sys.platform != "win32":
    # SIGTERM is unreliable on Windows — Ctrl+C (SIGINT) is the primary interrupt
    signal.signal(signal.SIGTERM, self._handler)
```

4. **Cloud CLI detection** (per CONTEXT.md — prompt per CLI, don't auto-install):
   ```powershell
   function Test-CLI($Name, $Command, $InstallUrl) {
       if (-not (Get-Command $Command -ErrorAction SilentlyContinue)) {
           Write-Host "[WARN] $Name CLI not found on PATH." -ForegroundColor Yellow
           $yn = Read-Host "  Open $Name CLI install page? (y/N)"
           if ($yn -match "^[Yy]$") {
               Start-Process $InstallUrl
           }
       } else {
           Write-Host "[OK]   $Name CLI found." -ForegroundColor Green
       }

   ```

5. **Windows long-path check:**
   ```powershell
   try {
       $longPath = (Get-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem" -Name "LongPathsEnabled" -ErrorAction Stop).LongPathsEnabled
       if ($longPath -ne 1) {
           Write-Host "[WARN] Windows long path support is disabled." -ForegroundColor Yellow
           Write-Host "       Run as Admin: New-ItemProperty -Path 'HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem' -Name 'LongPathsEnabled' -Value 1 -PropertyType DWORD -Force" -ForegroundColor Cyan
       }
   } catch {
       Write-Host "[WARN] Could not check long path support." -ForegroundColor Yellow
   }
   ```
