  <action>
    Create the Azure provider package and foundation modules:

    1. **`providers/azure/__init__.py`**: Package init with module docstring.

    2. **`providers/azure/auth.py`** — AzureAuthValidator implementing AuthValidator ABC:
       - Use DefaultAzureCredential from azure.identity. Warm credential by requesting token for `https://management.azure.com/.default`.
       - On success: list subscriptions via SubscriptionClient.subscriptions.list(), count Enabled ones, extract tenant_id from first subscription.
       - Return AuthResult with provider="azure", identity=f"Tenant: {tenant_id}", account_count=len(enabled_subs).
       - Catch CredentialUnavailableError: suggest "Run: az login  |  Or set AZURE_CLIENT_ID + AZURE_TENANT_ID + AZURE_CLIENT_SECRET".
       - Catch ClientAuthenticationError: check for "expired"/"refresh" in message for token expiry suggestion ("Run: az login"), else generic auth failed with "Check credentials. Run: az account list".
       - Catch Exception broadly as fallback with "Unexpected error" message.
       - Per CONTEXT.md: auto-detect Azure credentials, no auto-launch browser, contextual error suggestions.
       - Suppress Azure SDK logging: `logging.getLogger("azure").setLevel(logging.ERROR)` at module level.

    3. **`providers/azure/subscriptions.py`** — Subscription enumeration:
       - `list_subscriptions(credential) -> list[dict]`: Returns list of dicts with keys: id (subscription_id), display_name, tenant_id, state. Only includes Enabled subscriptions.
       - `get_subscription_display(sub_id: str, display_name: str) -> str`: Returns "Display Name (subscription-guid)" format per CONTEXT.md.
       - Uses SubscriptionClient(credential).subscriptions.list().

    4. **`providers/azure/client_factory.py`** — Per-subscription SDK client factory:
       - `AzureClients` dataclass holding all management clients for one subscription: compute (ComputeManagementClient), network (NetworkManagementClient), resource (ResourceManagementClient), dns (DnsManagementClient), privatedns (PrivateDnsManagementClient), storage (StorageManagementClient), sql (SqlManagementClient), cosmosdb (CosmosDBManagementClient), mysql (MySQLManagementClient from azure.mgmt.rdbms.mysql_flexibleservers), postgresql (PostgreSQLManagementClient from azure.mgmt.rdbms.postgresql_flexibleservers), redis (RedisManagementClient), web (WebSiteManagementClient), container (ContainerInstanceManagementClient), containerservice (ContainerServiceClient), apimanagement (ApiManagementClient), trafficmanager (TrafficManagerManagementClient), mgmt_groups (ManagementGroupsAPI), subscription (SubscriptionClient).
       - `create_subscription_clients(credential, subscription_id: str) -> AzureClients`: Creates all clients. Use context manager protocol where available.
       - Wrap each client creation in try/except: if an import fails (missing optional SDK package), set that client to None and log debug.

    5. **`requirements.txt`**: Add all Azure SDK packages per RESEARCH.md standard stack: azure-identity>=1.15.0, azure-mgmt-subscription>=3.0.0, azure-mgmt-resource>=23.0.0, azure-mgmt-compute>=33.0.0, azure-mgmt-network>=28.0.0, azure-mgmt-dns>=8.0.0, azure-mgmt-privatedns>=1.0.0, azure-mgmt-storage>=21.0.0, azure-mgmt-containerservice>=30.0.0, azure-mgmt-sql>=4.0.0b1, azure-mgmt-cosmosdb>=9.0.0, azure-mgmt-rdbms>=10.0.0, azure-mgmt-redis>=14.0.0, azure-mgmt-web>=7.0.0, azure-mgmt-containerinstance>=10.0.0, azure-mgmt-trafficmanager>=1.0.0, azure-mgmt-apimanagement>=4.0.0, azure-mgmt-managementgroups>=1.0.0. Also add azure-mgmt-appcontainers>=3.0.0 for Container Apps.

    6. **`tests/test_azure_auth.py`**: Unit tests using unittest.mock (no live Azure credentials):
       - Test auth validation success: mock DefaultAzureCredential + SubscriptionClient returning 3 enabled subs.

       - Test auth validation with expired token: mock ClientAuthenticationError with "expired" in message.
       - Test auth validation with generic auth failure: mock ClientAuthenticationError without "expired".
       - Test subscription listing: mock SubscriptionClient.subscriptions.list() returning mix of Enabled/Disabled.
       - Test get_subscription_display format.
       - Test client factory creates all clients (mock all SDK constructors).
