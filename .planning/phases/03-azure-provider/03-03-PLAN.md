    Create compute and hybrid networking collector modules. Import _extract_resource_group from networking module.

    **`collectors/compute.py`**:

    **collect_azure_vms(compute_client, network_client, subscription_id: str) -> list[CloudResource]:**
    - Use `compute_client.virtual_machines.list_all()` (subscription-level).
    - @retry_with_backoff(max_retries=3).
    - resource_type="azure-vm".
    - IP extraction: For each VM, iterate vm.network_profile.network_interfaces to get NIC IDs. Do NOT make extra API calls per NIC (RESEARCH.md Pitfall 4 — NICs collected separately as standalone assets). Set ip_addresses=[] on VMs since IPs are attributed via NIC collector.
    - details: resource_group, vm_size (vm.hardware_profile.vm_size), provisioning_state, nic_ids (list of NIC resource IDs for cross-reference).

    **collect_azure_vmss_instances(compute_client, network_client, subscription_id: str) -> list[CloudResource]:**
    - First list all VMSS: `compute_client.virtual_machine_scale_sets.list_all()`.
    - For each VMSS, enumerate instances: `compute_client.virtual_machine_scale_set_vms.list(rg, vmss_name)` (RESEARCH.md Pitfall 6 — must enumerate individual instances).
    - For each VMSS instance, get network interfaces: `network_client.network_interfaces.list_virtual_machine_scale_set_vm_network_interfaces(rg, vmss_name, instance_id)`.
    - Extract private IPs from each NIC's ip_configurations.
    - @retry_with_backoff(max_retries=3) on outer function.
    - resource_type="azure-vmss-instance" for individual instances.
    - details: resource_group, vmss_name, vmss_id, instance_id.
    - Per CONTEXT.md: enumerate individual VM instances within each VMSS for accurate IP counting.

    **`collectors/hybrid_networking.py`**: Extended networking collectors. All use @retry_with_backoff(max_retries=3). All use _extract_resource_group for resource group extraction.

    **collect_azure_load_balancers(network_client, subscription_id: str) -> list[CloudResource]:**
    - `network_client.load_balancers.list_all()`.
    - resource_type="azure-lb".
    - Extract IPs from frontend_ip_configurations: private_ip_address, and public_ip_address reference (ID only — don't resolve inline).
    - details: resource_group, lb_type (public vs internal based on frontend config).

    **collect_azure_app_gateways(network_client, subscription_id: str) -> list[CloudResource]:**
    - `network_client.application_gateways.list_all()`.
    - resource_type="azure-app-gateway".
    - Extract IPs from frontend_ip_configurations (private IPs where present).
    - details: resource_group, sku_name.

    **collect_azure_firewalls(network_client, subscription_id: str) -> list[CloudResource]:**
    - `network_client.azure_firewalls.list_all()`.
    - resource_type="azure-firewall".
    - Extract IPs from ip_configurations.
    - details: resource_group, firewall_policy_id.

    **collect_azure_nat_gateways(network_client, subscription_id: str) -> list[CloudResource]:**
    - `network_client.nat_gateways.list_all()`.
    - resource_type="azure-nat-gateway".
    - ip_addresses=[] (NAT gateways reference public IPs by ID).
    - details: resource_group, public_ip_address_ids.

    **collect_azure_private_endpoints(network_client, subscription_id: str) -> list[CloudResource]:**
    - `network_client.private_endpoints.list_all()`.
    - resource_type="azure-private-endpoint".
    - Extract IPs from each custom_dns_configs or network_interfaces (private IPs).
    - Per CONTEXT.md: count as standalone managed assets with their own IPs, don't dedup against linked PaaS resource.
    - details: resource_group, private_link_service_id.

    **collect_azure_vnet_peerings(network_client, subscription_id: str, vnets: list[CloudResource]) -> list[CloudResource]:**
    - Per-VNet: `network_client.virtual_network_peerings.list(rg, vnet_name)` (RESEARCH.md — per-VNet only).
    - resource_type="azure-vnet-peering".
    - ip_addresses=[].
    - details: resource_group, vnet_id, remote_vnet_id, peering_state.

    **collect_azure_express_route_circuits(network_client, subscription_id: str) -> list[CloudResource]:**
    - `network_client.express_route_circuits.list_all()`.
    - resource_type="azure-express-route".
    - details: resource_group, service_provider_name, peering_location, bandwidth_in_mbps.

    **collect_azure_vpn_gateways(network_client, subscription_id: str, vnets: list[CloudResource]) -> list[CloudResource]:**
    - Per-resource-group: `network_client.virtual_network_gateways.list(rg)` (RESEARCH.md — per-RG only). Iterate unique resource groups from VNets.
    - resource_type="azure-vpn-gateway".
    - Extract IPs from ip_configurations.
    - details: resource_group, gateway_type, vpn_type.

    **collect_azure_bastion_hosts(network_client, subscription_id: str) -> list[CloudResource]:**
    - `network_client.bastion_hosts.list()` (subscription-level).
    - resource_type="azure-bastion".
    - Extract IPs from ip_configurations.
    - details: resource_group, dns_name.

    - First list servers: `sql_client.servers.list()` (subscription-level).
    - For each server, list databases: `sql_client.databases.list_by_server(rg, server_name)`.
    - resource_type="azure-sql-db".
    - ip_addresses=[] (IPs attributed via private endpoints collected separately per CONTEXT.md PaaS IP extraction decision).

    **collect_azure_cosmosdb_accounts(cosmosdb_client, subscription_id: str) -> list[CloudResource]:**
    - `cosmosdb_client.database_accounts.list()` (subscription-level).
    - resource_type="azure-cosmosdb".
    - ip_addresses=[] (IPs via private endpoints).
    - details: resource_group, kind (cosmosdb.kind), consistency_policy, document_endpoint.

    **collect_azure_mysql_servers(mysql_client, subscription_id: str) -> list[CloudResource]:**
    - `mysql_client.servers.list()` (subscription-level, MySQL Flexible Servers).
    - resource_type="azure-mysql".
    - ip_addresses=[] (IPs via private endpoints).
    - details: resource_group, fully_qualified_domain_name, state, version.

    **collect_azure_postgresql_servers(postgresql_client, subscription_id: str) -> list[CloudResource]:**
    - `postgresql_client.servers.list()` (subscription-level, PostgreSQL Flexible Servers).
    - resource_type="azure-postgresql".
    - ip_addresses=[] (IPs via private endpoints).
    - details: resource_group, fully_qualified_domain_name, state, version.

    **collect_azure_redis_caches(redis_client, subscription_id: str) -> list[CloudResource]:**
    - `redis_client.redis.list_by_subscription()` (subscription-level).
    - resource_type="azure-redis".
    - ip_addresses: extract from redis.host_name resolved or static_ip if available. For Redis, host_name is a DNS name so ip_addresses=[] unless static_ip is set.
    - details: resource_group, host_name, port, ssl_port, sku_name.

    **`collectors/paas.py`**: PaaS and container collectors. All use @retry_with_backoff(max_retries=3).

    **collect_azure_app_services(web_client, subscription_id: str) -> list[CloudResource]:**
    - `web_client.web_apps.list()` (subscription-level).
    - Filter: include resources where kind does NOT contain "functionapp" (Functions handled separately).
    - resource_type="azure-app-service".
    - ip_addresses: Collect both inbound (default_host_name is DNS, but inbound_ip_addresses may have IPs) and outbound IPs (outbound_ip_addresses field, comma-separated string — split and add). Per CONTEXT.md: discover both inbound and outbound IPs.
    - details: resource_group, kind, state, default_host_name.

    **collect_azure_functions(web_client, subscription_id: str) -> list[CloudResource]:**
    - Same `web_client.web_apps.list()` but filter for kind containing "functionapp".
    - resource_type="azure-function".
    - ip_addresses: Same inbound/outbound extraction as App Service.
    - details: resource_group, kind, state, default_host_name.

    **collect_azure_container_instances(container_client, subscription_id: str) -> list[CloudResource]:**
    - `container_client.container_groups.list()` (subscription-level).
    - resource_type="azure-container-instance".
    - ip_addresses: Extract from container_group.ip_address.ip if present.
    - details: resource_group, os_type, provisioning_state, container_count (len of containers list).

    **collect_azure_container_apps(subscription_id: str) -> list[CloudResource]:**
    - Try to import azure.mgmt.appcontainers. If import fails, log debug and return [] (RESEARCH.md Open Question 3 — soft dependency).
    - If available: list all container apps via client.container_apps.list_by_subscription().
    - resource_type="azure-container-app".
    - ip_addresses=[] (Container Apps use managed ingress).
    - details: resource_group, managed_environment_id, provisioning_state.

    **collect_azure_aks_clusters(containerservice_client, subscription_id: str) -> list[CloudResource]:**
    - `containerservice_client.managed_clusters.list()` (subscription-level).
    - resource_type="azure-aks".
    - ip_addresses=[] (underlying VMs/VMSS capture IPs).
    - details: resource_group, kubernetes_version, node_count (sum of agent pool counts), fqdn.

    **collect_azure_api_management(apimanagement_client, subscription_id: str) -> list[CloudResource]:**
    - `apimanagement_client.api_management_service.list()` (subscription-level).
    - resource_type="azure-api-management".
    - ip_addresses: Extract from public_ip_addresses if present, plus private_ip_addresses.
    - details: resource_group, sku_name, gateway_url.
