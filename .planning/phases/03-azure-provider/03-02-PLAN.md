    Create the Azure networking collectors module:

    1. **`collectors/__init__.py`**: Package init with module docstring.

    2. **`collectors/networking.py`**: Azure networking resource collectors. Include a shared helper `_extract_resource_group(resource_id: str) -> str` that parses ARM resource IDs to extract resource group name (case-insensitive "resourcegroups" match per RESEARCH.md Pattern 3).

    **collect_azure_vnets(network_client, subscription_id: str) -> list[CloudResource]:**
    - Use `network_client.virtual_networks.list_all()` (subscription-level, per RESEARCH.md).
    - @retry_with_backoff(max_retries=3) decorator.
    - resource_type="azure-vnet", provider="azure", region=vnet.location, name=vnet.name.
    - resource_id = vnet.id (full ARM resource ID per CONTEXT.md).
    - ip_addresses=[] (VNets don't have IPs).
    - tags=dict(vnet.tags) if vnet.tags else {}.
    - details: resource_group (from _extract_resource_group), address_prefixes (from vnet.address_space.address_prefixes), dhcp_dns_servers (from vnet.dhcp_options.dns_servers if present).
    - Use attribute access on SDK model objects, NOT dict access (RESEARCH.md Pitfall 2).

    **collect_azure_subnets(network_client, subscription_id: str, vnets: list[CloudResource]) -> list[CloudResource]:**
    - Iterate over discovered VNets and call `network_client.subnets.list(rg, vnet_name)` per VNet (RESEARCH.md Pitfall 1 — subnets have no subscription-level list).
    - @retry_with_backoff(max_retries=3) on the outer function.
    - resource_type="azure-subnet", region inherited from parent VNet.
    - resource_id = subnet.id.
    - details: resource_group, vnet_id (parent VNet resource_id), address_prefix (subnet.address_prefix).

    **collect_azure_dhcp_configs(vnets: list[CloudResource]) -> list[CloudResource]:**
    - NO SDK call needed — extract from VNet details.
    - For each VNet that has non-empty dhcp_dns_servers in details, create a separate CloudResource.
    - resource_type="azure-dhcp-config", resource_id=f"{vnet.resource_id}/dhcpOptions" (per RESEARCH.md Open Question 2).
    - details: resource_group, vnet_id, dns_servers list.
    - No @retry_with_backoff needed (pure data extraction, no API call).

    **collect_azure_nics(network_client, subscription_id: str) -> list[CloudResource]:**
    - Use `network_client.network_interfaces.list_all()` (subscription-level).
    - @retry_with_backoff(max_retries=3).
    - resource_type="azure-nic".
    - Extract IPs from nic.ip_configurations: each ip_config.private_ip_address added to ip_addresses list. Public IPs are NOT resolved inline (RESEARCH.md Pitfall 4 — collected separately).
    - details: resource_group, vm_id (nic.virtual_machine.id if attached), ip_configuration_count.
    - Per CONTEXT.md: NICs are standalone managed assets, unattached NICs with IPs count.

    **collect_azure_public_ips(network_client, subscription_id: str) -> list[CloudResource]:**
    - Use `network_client.public_ip_addresses.list_all()` (subscription-level).
    - @retry_with_backoff(max_retries=3).
    - resource_type="azure-public-ip".
    - ip_addresses=[pip.ip_address] if pip.ip_address else [].
    - details: resource_group, allocation_method, ip_configuration_id (for cross-reference to NIC).

    3. **`tests/test_azure_collectors_networking.py`**: Tests using unittest.mock (mock Azure SDK client objects):
    - Test VNet collection: mock network_client.virtual_networks.list_all() returning 2 VNets with address spaces and DHCP options. Verify resource_type, resource_id, details.
    - Test VNet with no DHCP options.
    - Test subnet collection from 2 VNets: mock network_client.subnets.list() for each VNet. Verify subnet inherits VNet region.
    - Test subnet collection skips VNets with missing resource_group.
    - Test DHCP config extraction: 3 VNets, 2 with DHCP options, verify 2 DHCP configs created.
    - Test DHCP config skips VNets without dns_servers.
    - Test NIC collection: mock 3 NICs, one with 2 ip_configurations (2 private IPs), one with 1 IP, one unattached. Verify all 3 discovered.
    - Test public IP collection: mock 2 public IPs, one allocated, one not yet allocated (ip_address=None). Verify IPs captured correctly.
    - Test _extract_resource_group with standard ARM ID.
    - Test _extract_resource_group with empty/malformed ID.

    Create the Azure DNS collectors module:

    **`collectors/dns.py`**: Azure public and private DNS collectors. Import _extract_resource_group from networking module.

    **collect_azure_dns_zones(dns_client, subscription_id: str) -> list[CloudResource]:**
    - Use `dns_client.zones.list()` (subscription-level per RESEARCH.md).
    - @retry_with_backoff(max_retries=3).
    - resource_type="azure-dns-zone", region="global" (DNS is global per AWS Route53 pattern).
    - resource_id = zone.id.
    - details: resource_group, zone_type="public", record_count (zone.number_of_record_sets if available).

    **collect_azure_dns_records(dns_client, subscription_id: str, zones: list[CloudResource]) -> list[CloudResource]:**
    - For each public DNS zone, call `dns_client.record_sets.list_by_dns_zone(rg, zone_name)` (per-zone per RESEARCH.md Pitfall 7 — records require zone context).
    - @retry_with_backoff(max_retries=3) on the outer function. Wrap each zone iteration in try/except for per-zone error isolation.
    - resource_type="azure-dns-record", region="global".
    - resource_id = record_set.id (full ARM resource ID — globally unique, avoids Pitfall 7).
    - details: resource_group, zone_name, record_type (parsed from record_set.type, take last segment after "/"), ttl.
    - Per CONTEXT.md: enumerate ALL DNS records, no filtering.

    **collect_azure_private_dns_zones(privatedns_client, subscription_id: str) -> list[CloudResource]:**
    - Use `privatedns_client.private_zones.list()` (subscription-level).
    - @retry_with_backoff(max_retries=3).
    - resource_type="azure-private-dns-zone", region="global".
    - details: resource_group, zone_type="private", record_count.

    **collect_azure_private_dns_records(privatedns_client, subscription_id: str, zones: list[CloudResource]) -> list[CloudResource]:**
    - For each private DNS zone, call `privatedns_client.record_sets.list(rg, zone_name)` (per-zone).
    - @retry_with_backoff(max_retries=3) on outer function. Per-zone error isolation.
    - resource_type="azure-private-dns-record", region="global".
    - resource_id = record_set.id.
    - details: resource_group, zone_name, record_type, ttl.

    - Verify all resources have provider="azure" and region="global".
