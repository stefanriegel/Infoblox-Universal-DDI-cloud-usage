  <name>Task 1: Fix base.html conditional HTMX initial tab load</name>
  <files>src/cloud_usage/dashboard/templates/base.html</files>
  <action>
    The current base.html hardcodes `hx-get="/tab/progress"` in the default `{% block content %}`. When /nios or /ad renders base.html with active_tab="nios"/"ad", the wrong tab fires on load.

    **The fix:** Replace the hardcoded hx-get path with a Jinja2 expression that maps active_tab to the correct tab route URL.

    Change the tab-container div's hx-get attribute from:
    ```html
    <div id="tab-container"
         hx-get="/tab/progress" hx-trigger="load" hx-target="#tab-container">
    ```

    To:
    ```html
    <div id="tab-container"
         hx-get="/tab/{{ active_tab if active_tab in ('progress', 'nios', 'ad') else 'progress' }}" hx-trigger="load" hx-target="#tab-container">
    ```

    This uses the existing `active_tab` value already in the template context (set by _get_tab_context):
    - active_tab="progress" → hx-get="/tab/progress" (Cloud Calculator — same as before)
    - active_tab="nios" → hx-get="/tab/nios" (NIOS Calculator auto-loads)
    - active_tab="ad" → hx-get="/tab/ad" (AD Calculator auto-loads)
    - active_tab="results" or "summary" or anything else → falls back to /tab/progress (safe default)

    The fallback `else 'progress'` ensures: if someone renders base.html without active_tab set, or with active_tab="results"/"summary" (existing tab states), the Cloud tab auto-loads as before — preserving all existing behavior.

    Do NOT change any other part of base.html. This is a one-line change to the hx-get attribute.
  </action>
