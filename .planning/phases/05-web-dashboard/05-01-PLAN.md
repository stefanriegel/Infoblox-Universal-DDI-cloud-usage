    5. **src/cloud_usage/dashboard/services/event_bridge.py** -- Implement EventBridge class per Research Pattern 1:
       - `__init__`: sets `_queue = None`, `_subscribers = []` (list of subscriber queues for fan-out)
       - `async start()`: creates `janus.Queue()` and stores it
       - `emit(event_type: str, data: dict) -> None`: thread-safe, puts `{"event": event_type, "data": data}` on sync_q. Also copies to all subscriber queues for multi-client support.
       - `emit_done() -> None`: calls `emit("scan_complete", {})`
       - `async subscribe() -> AsyncGenerator[str, None]`: creates a per-subscriber janus.Queue, registers it, yields SSE-formatted strings. Sends `: keepalive\n\n` every 25 seconds on timeout (Pitfall 3). Breaks on `scan_complete` event. Unregisters queue on exit.
       - `async close()`: closes all queues
       - Use `from __future__ import annotations` for Python 3.9 compatibility.

    6. **src/cloud_usage/dashboard/services/scan_manager.py** -- Implement ScanManager per Research Pattern 5:
       - `ScanState` enum: IDLE, RUNNING, COMPLETE, CANCELLED, ERROR
       - `ScanConfig` dataclass: providers (list[str]), include_accounts (dict), exclude_accounts (dict)
       - `ScanManager` class: `_state`, `_lock`, `_resources`, `_errors`, `_output_paths`, `_config`, `_last_config_path`
       - Properties: `state`, `resources`, `errors`, `output_paths`, `config`
       - Methods: `can_start() -> bool` (True when IDLE/COMPLETE/CANCELLED/ERROR), `start(config)`, `set_resources(resources)`, `set_errors(errors)`, `set_output_paths(paths)`, `set_state(state)`, `cancel()`
       - `save_scan_config(config)` / `load_scan_config()`: persist to `output/.last_scan_config.json` per Research pattern
       - Thread-safe: all state access behind `self._lock`

    7. **src/cloud_usage/dashboard/app.py** -- Implement `create_app()` factory per Research Pattern:
       - Use `@asynccontextmanager` lifespan (NOT deprecated `@app.on_event`)
       - In lifespan startup: create EventBridge, call `await event_bridge.start()`, create ScanManager, store both on `app.state`
       - In lifespan shutdown: call `await event_bridge.close()`
       - Mount StaticFiles at `/static` pointing to `dashboard/static/` directory (use `Path(__file__).parent / "static"`)
       - Set up Jinja2Templates pointing to `dashboard/templates/` directory, store on `app.state`
       - Include pages_router from routes/pages.py
       - Set title="UDDI Cloud Usage Estimator"
