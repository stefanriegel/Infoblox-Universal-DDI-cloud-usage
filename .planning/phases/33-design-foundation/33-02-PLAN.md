  <action>
Download the Inter variable font (roman/upright, latin + latin-ext) WOFF2 file and place it at `src/cloud_usage/dashboard/static/inter-variable.woff2`.

Download source: https://github.com/rsms/inter/releases/latest — look for `Inter.var.woff2` or `inter-roman.var.woff2` in the release assets. This is the official Inter variable font maintained by Rasmus Andersson.

Alternative source if GitHub releases are slow: https://fontsource.org/fonts/inter — download the variable font WOFF2.

The file must:
- Be a valid WOFF2 binary (starts with `wOF2` magic bytes)
- Cover font-weight range 100–900 (variable font axis)
- Cover Latin and Latin-Extended unicode ranges
- Be approximately 100–130KB in size

Use curl or wget to download directly into the static directory:
```
curl -L "https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip" -o /tmp/inter.zip
unzip -p /tmp/inter.zip "extras/woff2/Inter.var.woff2" > src/cloud_usage/dashboard/static/inter-variable.woff2
```

If the zip structure differs, unzip to /tmp/inter-extract/ first and find the correct woff2 file path.

The file must be accessible at runtime via FastAPI's StaticFiles mount at /static/inter-variable.woff2.
