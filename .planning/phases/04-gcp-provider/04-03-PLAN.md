    **src/cloud_usage/providers/gcp/collectors/compute.py**:

    `collect_gcp_vms(instances_client, project_id) -> list[CloudResource]`:
    - Use `instances_client.aggregated_list(request=compute_v1.AggregatedListInstancesRequest(project=project_id))`.
    - `@retry_with_backoff(max_retries=3)` decorator.
    - For each (zone_key, scoped_list):
      - Check `if not scoped_list.instances: continue` per Pitfall 2.
      - Extract zone from key: `zone_key.split("/")[-1]` (format: "zones/us-central1-a").
      - Extract region from zone: `zone_name.rsplit("-", 1)[0]` (e.g., "us-central1-a" -> "us-central1").
      - For each instance:
        - IP extraction per Pitfall 6 (CRITICAL: use `network_i_p` not `network_ip`):
          - Iterate `instance.network_interfaces` (or empty list if None).
          - Private IP: `iface.network_i_p` (if not empty/None).
          - Public IP: iterate `iface.access_configs` (or empty list), `ac.nat_i_p` (if not empty/None).
        - `resource_id`: `instance.self_link` or `f"projects/{project_id}/zones/{zone_name}/instances/{instance.name}"`.
        - `resource_type`: `"gcp-vm"`.
        - `provider`: `"gcp"`.
        - `account_id`: `project_id`.
        - `region`: extracted region.
        - `name`: `instance.name`.
        - `ip_addresses`: combined private + public IPs.
        - `tags`: `dict(instance.labels) if instance.labels else {}`.
        - `details`: `{"zone": zone_name, "machine_type": (instance.machine_type or "").split("/")[-1], "status": instance.status}`.

    `collect_gcp_forwarding_rules(forwarding_rules_client, project_id) -> list[CloudResource]`:
    - Use `forwarding_rules_client.aggregated_list(request=compute_v1.AggregatedListForwardingRulesRequest(project=project_id))`.
    - `@retry_with_backoff(max_retries=3)` decorator.
    - For each (region_key, scoped_list):
      - Check `if not scoped_list.forwarding_rules: continue`.
      - Extract region from key: `region_key.split("/")[-1]`.
      - For each rule:
        - `ip_addresses`: `[rule.I_p_address]` if `rule.I_p_address` is not empty/None. NOTE: The GCP compute SDK field for IP address on forwarding rules is `I_p_address` (capital I, lowercase p, with underscores) -- this is the auto-generated Python name from the proto field `IPAddress`. Verify this during implementation by checking the actual SDK attribute name. If the field is actually `i_p_address` (all lowercase) or `ip_address`, use that instead. Check by printing `dir(rule)` or `rule.__class__.__dict__` in tests.
        - `resource_type`: `"gcp-forwarding-rule"`.
        - `region`: extracted region (may be "global" for global forwarding rules -- check key prefix).
        - `details`: `{"load_balancing_scheme": getattr(rule, "load_balancing_scheme", ""), "target": (getattr(rule, "target", "") or "").split("/")[-1], "ip_protocol": getattr(rule, "ip_protocol", "")}`.
