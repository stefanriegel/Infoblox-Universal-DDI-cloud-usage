    **src/cloud_usage/providers/gcp/__init__.py**: Package marker with module docstring.

    **src/cloud_usage/providers/gcp/auth.py**: GCPAuthValidator implementing AuthValidator ABC.
    - `validate()` calls `google.auth.default()` to get credentials, then `credentials.refresh(Request())` to validate them.
    - On success, count accessible projects using `resourcemanager_v3.ProjectsClient.search_projects(query="state:ACTIVE")`. Return `AuthResult(success=True, identity="Project: {project}" or "ADC (no default project)", account_count=max(project_count, 1))`.
    - Handle ImportError: return AuthResult with error "GCP SDK not installed", suggestion "Run: pip install google-auth google-cloud-resource-manager".
    - Handle DefaultCredentialsError (by class name): return AuthResult with error "No GCP credentials found", suggestion "Run: gcloud auth application-default login  |  Or set GOOGLE_APPLICATION_CREDENTIALS=...".
    - Handle RefreshError (by class name): return AuthResult with error "GCP credentials expired", suggestion "Run: gcloud auth application-default login".
    - Generic exceptions: return AuthResult with error message and generic suggestion.
    - Use exception class name matching (`type(exc).__name__`) for GCP exceptions, consistent with Azure pattern (SDK may not be installed).
    - Suppress google SDK logging: `logging.getLogger("google").setLevel(logging.ERROR)` at module level.

    **src/cloud_usage/providers/gcp/projects.py**: Project enumeration with filtering and API pre-checks.
    - `ProjectInfo` dataclass with fields: `project_id: str`, `compute_enabled: bool`, `dns_enabled: bool`, `sqladmin_enabled: bool`, `container_enabled: bool`.
    - `enumerate_gcp_projects(credentials, adc_project, project, org_id, include_patterns, exclude_patterns) -> list[ProjectInfo]`:
      - If explicit project provided (project param > GOOGLE_CLOUD_PROJECT env > adc_project), return single-element list (bypass enumeration).
      - Otherwise, use `resourcemanager_v3.ProjectsClient.search_projects(query="state:ACTIVE")`. If org_id, add `parent:organizations/{org_id}` to query.
      - Apply include/exclude glob filters using `fnmatch.fnmatch()`. Include takes precedence (if include provided, only match include; exclude is applied only when no include).
      - Zero projects: return empty list (caller handles the error message).
      - Per-project API pre-check using `ServiceUsageClient.batch_get_services()` for compute, dns, sqladmin, and container APIs. On PermissionDenied: treat all as unavailable (False). On other transient errors: assume enabled (True).
      - Log `[Skip] {project_id}: {API} disabled` for each disabled API.
      - Return list of ProjectInfo.
    - Reference legacy `gcp_discovery/config.py` for the enumeration logic (search_projects, org-scoping, API pre-checks, filters) but rewrite in new architecture style (no sys.exit, return data structures).

    **src/cloud_usage/providers/gcp/client_factory.py**: GCP SDK client creation.
    - `GCPClients` dataclass with fields for all shared clients:
      - `instances: Any | None` (compute_v1.InstancesClient)
      - `networks: Any | None` (compute_v1.NetworksClient)
      - `subnetworks: Any | None` (compute_v1.SubnetworksClient)
      - `addresses: Any | None` (compute_v1.AddressesClient)
      - `global_addresses: Any | None` (compute_v1.GlobalAddressesClient)
      - `forwarding_rules: Any | None` (compute_v1.ForwardingRulesClient)
      - `disks: Any | None` (compute_v1.DisksClient)
      - `instance_groups: Any | None` (compute_v1.InstanceGroupsClient)
      - `url_maps: Any | None` (compute_v1.UrlMapsClient)
      - `container: Any | None` (container_v1.ClusterManagerClient)
      - `sqladmin: Any | None` (googleapiclient discovery service)
    - `create_shared_clients(credentials) -> GCPClients`: Create all clients once. These are project-agnostic (project passed per-call). Use _try_create wrapper per Azure pattern for graceful handling of missing SDK packages. DNS client is NOT included here (created per-project in discover_account).
    - For sqladmin: use `googleapiclient.discovery.build('sqladmin', 'v1', credentials=credentials, cache_discovery=False)`.
