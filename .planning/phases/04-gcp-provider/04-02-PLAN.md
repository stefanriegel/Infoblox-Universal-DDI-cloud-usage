    Create networking collectors for GCP DDI objects and IP-bearing resources.

    **src/cloud_usage/providers/gcp/collectors/networking.py**:

    `collect_gcp_vpcs(networks_client, project_id) -> list[CloudResource]`:
    - Use `networks_client.list(project=project_id)` (VPC networks are global, no aggregatedList).
    - `@retry_with_backoff(max_retries=3)` decorator.
    - For each network:
      - `resource_id`: `network.self_link` or `f"projects/{project_id}/global/networks/{network.name}"`.
      - `resource_type`: `"gcp-vpc"`.
      - `provider`: `"gcp"`.
      - `account_id`: `project_id`.
      - `region`: `"global"`.
      - `name`: `network.name`.
      - `ip_addresses`: `[]` (VPC networks are DDI containers, no IPs).
      - `tags`: `dict(network.labels) if network.labels else {}` (GCP networks DO NOT have labels in the API, so this will be empty dict -- but check defensively).
      - `details`: `{"auto_create_subnetworks": getattr(network, "auto_create_subnetworks", None)}`.

    `collect_gcp_subnets(subnetworks_client, project_id) -> list[CloudResource]`:
    - Use `subnetworks_client.aggregated_list(request=compute_v1.AggregatedListSubnetworksRequest(project=project_id))`.
    - `@retry_with_backoff(max_retries=3)` decorator.
    - For each (region_key, scoped_list) pair:
      - Check `if not scoped_list.subnetworks: continue` per Pitfall 2 (empty scoped lists).
      - Extract region from key: `region_key.split("/")[-1]` (format: "regions/us-central1").
      - For each subnetwork:
        - `resource_id`: `subnetwork.self_link` or `f"projects/{project_id}/regions/{region}/subnetworks/{subnetwork.name}"`.
        - `resource_type`: `"gcp-subnet"`.
        - `region`: extracted region.
        - `ip_addresses`: `[]` (subnets are DDI objects, not IP-bearing).
        - `details`: `{"ip_cidr_range": subnetwork.ip_cidr_range, "network": (subnetwork.network or "").split("/")[-1]}`.

    `collect_gcp_reserved_ips(addresses_client, global_addresses_client, project_id) -> list[CloudResource]`:
    - Two sources: regional addresses (aggregatedList) + global addresses (list).
    - `@retry_with_backoff(max_retries=3)` decorator.
    - Regional: `addresses_client.aggregated_list(request=compute_v1.AggregatedListAddressesRequest(project=project_id))`.
      - Check `if not scoped_list.addresses: continue`.
      - Extract region from key.
      - For each address: `ip_addresses=[address.address]` if address.address is not empty.
      - `resource_type`: `"gcp-reserved-ip"`.
      - `details`: `{"address_type": address.address_type, "status": address.status, "purpose": getattr(address, "purpose", "")}`.
    - Global: `global_addresses_client.list(project=project_id)`.
      - `region`: `"global"`.
      - Same CloudResource pattern.
    - Combine both lists and return.

    **tests/test_gcp_collectors_networking.py**: Unit tests with unittest.mock.
    - Mock compute_v1 clients with MagicMock.
    - Test collect_gcp_vpcs: returns CloudResource with resource_type="gcp-vpc", region="global".
    - Test collect_gcp_vpcs empty project: returns [].
    - Test collect_gcp_subnets via mocked aggregated_list: returns resources across multiple regions.
    - Test collect_gcp_subnets skips empty scoped lists.
    - Test collect_gcp_reserved_ips: regional + global addresses combined.
    - Test collect_gcp_reserved_ips with empty addresses.
    - Test IP extraction: address.address populates ip_addresses field.
    - Target: ~15-18 tests.

    Create DNS collectors for GCP Cloud DNS zones and records.

    **src/cloud_usage/providers/gcp/collectors/dns.py**:

    `collect_gcp_dns_zones(dns_client, project_id) -> list[CloudResource]`:
    - Use `dns_client.list_zones()` (dns.Client is per-project, created with `project=project_id`).
    - `@retry_with_backoff(max_retries=3)` decorator.
    - For each zone:
      - `resource_id`: `f"projects/{project_id}/managedZones/{zone.name}"`.
      - `resource_type`: `"gcp-dns-zone"`.
      - `region`: `"global"` (DNS is global).
      - `name`: `zone.dns_name`.
      - `ip_addresses`: `[]`.
      - `details`: `{"zone_name": zone.name, "dns_name": zone.dns_name, "visibility": getattr(zone, "visibility", "public")}`.

    `collect_gcp_dns_records(dns_client, project_id, zones: list[CloudResource]) -> list[CloudResource]`:
    - Iterate over discovered zones (passed as parameter for dependency ordering).
    - For each zone, get the zone object: `zone_obj = dns_client.zone(zone_name)` where `zone_name` is extracted from `zone.details["zone_name"]`.
    - Call `zone_obj.list_resource_record_sets()` to get all records.
    - `@retry_with_backoff(max_retries=3)` decorator.
    - Per-zone error isolation: wrap each zone's record enumeration in try/except, log warning and continue on failure (consistent with Azure DNS pattern).
    - For each record_set:
      - `resource_id`: `f"projects/{project_id}/managedZones/{zone_name}/{record_set.name}/{record_set.record_type}"`.
      - `resource_type`: `"gcp-dns-record"`.
      - `name`: `record_set.name`.
      - `ip_addresses`: Extract IPs from A and AAAA record types. `record_set.rrdatas` contains the values. For A records: each value is an IPv4 address. For AAAA records: each value is an IPv6 address. For other record types: `ip_addresses=[]`.
      - `details`: `{"record_type": record_set.record_type, "ttl": record_set.ttl, "zone_name": zone_name}`.
    - Full record enumeration: Include ALL record types (SOA, NS, A, AAAA, CNAME, MX, TXT, SRV, etc.) per CONTEXT.md decision. No filtering.

    **tests/test_gcp_collectors_dns.py**: Unit tests with unittest.mock.
    - Mock dns.Client and zone objects.
    - Test collect_gcp_dns_zones: returns zones with resource_type="gcp-dns-zone".
    - Test collect_gcp_dns_zones empty: returns [].
    - Test collect_gcp_dns_records: iterates zones and returns records.
    - Test DNS record IP extraction for A and AAAA records.
    - Test non-IP record types (CNAME, MX, TXT) have ip_addresses=[].
    - Test SOA and NS records are included (not filtered per CONTEXT.md).
    - Test per-zone error isolation: one zone failure doesn't prevent other zones from being collected.
    - Test empty zone (no records): returns [] for that zone.
    - Target: ~12-15 tests.
