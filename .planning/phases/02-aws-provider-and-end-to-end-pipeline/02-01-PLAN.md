  <action>
    Create the providers package structure (empty __init__.py files for providers/ and providers/aws/).

    **auth.py** - AWSAuthValidator implementing AuthValidator ABC:
    - Constructor takes optional profile: str | None parameter
    - validate() method: creates boto3.Session(profile_name=profile), calls sts.get_caller_identity() to verify credentials
    - On success: tries organizations.list_accounts() paginator to count active accounts (filter Status=="ACTIVE"). On Organizations ClientError (AccessDenied), fall back to account_count=1
    - Returns AuthResult(provider="aws", success=True, identity=arn, account_count=N)
    - Catches SSOTokenLoadError: returns AuthResult with success=False, error_message="AWS SSO token expired or not found", suggestion="Run: aws sso login --profile {profile}"
    - Catches NoCredentialsError: returns AuthResult with success=False, error_message="No AWS credentials found", suggestion="Configure AWS credentials or run 'aws sso login'"
    - Catches ClientError with generic message for other failures
    - provider_name property returns "aws"

    **organizations.py** - Two functions:
    - list_organization_accounts(session: boto3.Session) -> list[dict]: Uses organizations client get_paginator("list_accounts"), returns list of dicts with AccountId and Status. Only returns accounts with Status=="ACTIVE". On AccessDeniedException, returns empty list (caller handles fallback).
    - assume_cross_account_role(sts_client, account_id: str, role_name: str = "OrganizationAccountAccessRole", session_name: str = "InfobloxUDDI-Discovery") -> boto3.Session: Calls sts.assume_role with RoleArn=f"arn:aws:iam::{account_id}:role/{role_name}", DurationSeconds=3600, returns new boto3.Session with temporary credentials.

    **regions.py** - Single function:
    - get_enabled_regions(session: boto3.Session) -> list[str]: Creates ec2 client in us-east-1, calls describe_regions with Filter opt-in-status=["opt-in-not-required", "opted-in"], returns sorted list of RegionName strings.

    **tests/test_aws_auth.py** - Tests using @mock_aws from moto:
    - Test validate() succeeds with valid credentials (returns success=True, identity contains ARN)
    - Test validate() with Organizations returns correct account_count
    - Test validate() falls back to single-account when Organizations fails
    - Test list_organization_accounts returns only ACTIVE accounts
    - Test assume_cross_account_role returns valid session
    - Test get_enabled_regions returns sorted region list

    Use `from __future__ import annotations` in all files. Add `import sys; sys.path.insert(0, "src")` in test files per Phase 1 pattern.
  </action>
