    **xlsx_report.py** - Uses xlsxwriter (per research recommendation: pure Python, write-only, rich formatting).

    **write_xlsx_report(filepath: str, resources: list[CloudResource], account_summaries: dict[str, dict], errors: list, provider: str) -> str:**
    Returns the filepath written.

    **Formats** (defined once at workbook level):
    - header_fmt: bold, bg_color="#4472C4", font_color="white", border=1, text_wrap=True
    - even_row: bg_color="#D9E2F3", border=1
    - odd_row: border=1
    - number_fmt: border=1, num_format="#,##0"
    - counted_yes: border=1, font_color="#006100", bg_color="#C6EFCE"
    - counted_no: border=1, font_color="#9C0006", bg_color="#FFC7CE"
    - total_row: bold=True, border=1, bg_color="#E2EFDA", num_format="#,##0"

    **Detail sheet:**
    - Frozen header row (freeze_panes(1, 0))
    - Columns: Resource ID, Type, Account, Region, Name, IP Addresses, IP Count, Counted, Category, Skip Reason, Tags
    - One row per resource from the resources list
    - IP Addresses: comma-separated string of all IPs
    - IP Count: integer count of IPs
    - Counted: "Yes" or "No" (use counted_yes/counted_no format)
    - Category: "DDI", "IP", "Asset", or "-"
    - Skip Reason: the skip_reason string or empty
    - Tags: "key1=val1; key2=val2" format
    - Auto-size columns based on header width (minimum 12, maximum 40 chars)

    **Summary sheet:**
    - Frozen header row
    - Row per account with columns: Account ID, DDI Objects, DDI Tokens, Active IPs, IP Tokens, Managed Assets, Asset Tokens, Total Tokens
    - Values from account_summaries dict (keyed by account_id)
    - Final row: "PROVIDER TOTAL" with sum of all accounts
    - Use total_row format for the provider total row
    - Bold headers with header_fmt

    **Warnings sheet:**
    - Columns: Account, Region, Resource Type, Error, Suggestion
    - One row per error
    - If no errors, write single row "No errors occurred during discovery"

    workbook.close() at the end. Handle xlsxwriter.exceptions if any.

    **Tests:**
    - Create mock resources and account_summaries, write XLS, verify file exists and is non-empty
    - Verify Detail sheet has correct row count (header + resources)
    - Verify Summary sheet has correct account count + total row
    - Verify Warnings sheet handles empty errors and non-empty errors
    - Use openpyxl to read back the generated XLS for content verification in tests (read-only verification is fine -- we only use xlsxwriter for writing)

    Returns filepath written.
    - Use csv.writer from stdlib
    - Header row: Account ID, DDI Objects, Active IPs, Managed Assets, DDI Tokens, IP Tokens, Asset Tokens, Total Tokens

    **proof_manifest.py** - SHA-256 JSON proof of scan integrity.

    **write_proof_manifest(filepath: str, resources: list[CloudResource], account_summaries: dict[str, dict], scan_metadata: dict, provider: str) -> str:**
    Returns filepath written.

    Build manifest dict:
    - version: "1.0"
    - provider: provider name
    - scan_timestamp: from scan_metadata
    - scan_duration_seconds: from scan_metadata
    - scope: {accounts_scanned: int, regions_scanned: int, resource_types: list of unique types}
    - ratios: {ddi_per_token: 25, ips_per_token: 13, assets_per_token: 3}
    - counts: {total_resources: int, counted_resources: int, skipped_resources: int, ddi_objects: int, active_ips: int, managed_assets: int}
    - tokens: {ddi_tokens: int, ip_tokens: int, asset_tokens: int, total_tokens: int}
    - resource_hash: SHA-256 of sorted JSON representation of all resource IDs + categories
    - manifest_hash: SHA-256 of all above fields (excluding manifest_hash itself)

    Hashing approach:
    1. Build resource_data = sorted list of (resource_id, resource_type, counted, category) tuples
    2. resource_hash = hashlib.sha256(json.dumps(resource_data, sort_keys=True).encode()).hexdigest()
    3. Build manifest without manifest_hash field
    4. manifest_hash = hashlib.sha256(json.dumps(manifest, sort_keys=True).encode()).hexdigest()
    5. Add manifest_hash to manifest
    6. Write manifest as indented JSON
