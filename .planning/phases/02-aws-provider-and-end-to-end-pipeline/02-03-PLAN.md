Implement AWS resource collectors for DDI objects and core networking resources. These collectors use boto3 paginators to discover VPCs, subnets, Route53 zones/records, DHCP option sets, ENIs, Elastic IPs, and gateways.

Purpose: DDI object discovery is the first layer of the token calculation pipeline. These collectors produce the CloudResource instances that flow through categorization, counting, and reporting.
Output: Working collectors for all DDI and core networking AWS resource types with full IP extraction.
</objective>

  <action>
    Create collectors/__init__.py (empty).

    **ec2.py** - All functions take (ec2_client, account_id: str, region: str) and return list[CloudResource]. Use @retry_with_backoff(max_retries=3) decorator from Phase 1 on all collector functions. Always use get_paginator() for all describe/list calls per research anti-pattern guidance.

    **collect_vpcs(ec2_client, account_id, region):**
    - Paginate describe_vpcs
    - resource_type="vpc", resource_id=VpcId, name from Name tag
    - ip_addresses: extract CidrBlock (not an IP, but store in details)
    - details: {vpc_id: VpcId, cidr_block: CidrBlock, is_default: IsDefault, state: State, owner_id: OwnerId, dhcp_options_id: DhcpOptionsId}
    - tags from Tags list

    **collect_subnets(ec2_client, account_id, region):**
    - Paginate describe_subnets
    - resource_type="subnet", resource_id=SubnetId
    - details: {vpc_id: VpcId, cidr_block: CidrBlock, availability_zone: AvailabilityZone, owner_id: OwnerId}

    **collect_enis(ec2_client, account_id, region):**
    - Paginate describe_network_interfaces (MUST paginate per Pitfall 7)
    - resource_type="eni", resource_id=NetworkInterfaceId
    - ip_addresses: ALL private IPs from PrivateIpAddresses[] + Association.PublicIp from each, plus Ipv6Addresses[]
    - details: {vpc_id: VpcId, subnet_id: SubnetId, attachment_id: Attachment.AttachmentId or None, attachment_instance_id: Attachment.InstanceId or None, status: Status, interface_type: InterfaceType, owner_id: OwnerId}
    - Only include ENIs where Status != "available" with no attachment OR include all (let asset_dedup handle folding). Include ALL ENIs -- the asset_dedup module in Plan 02 handles folding.

    **collect_eips(ec2_client, account_id, region):**
    - describe_addresses (no paginator needed, returns all)
    - resource_type="elastic-ip", resource_id=AllocationId
    - ip_addresses: [PublicIp] (and PrivateIpAddress if associated)
    - details: {vpc_id: association VpcId if exists, instance_id: InstanceId, association_id: AssociationId, network_interface_id: NetworkInterfaceId}

    **collect_nat_gateways(ec2_client, account_id, region):**
    - Paginate describe_nat_gateways, filter State != "deleted"
    - resource_type="nat-gateway", resource_id=NatGatewayId
    - ip_addresses: from NatGatewayAddresses[]: both PrivateIp and PublicIp
    - details: {vpc_id: VpcId, subnet_id: SubnetId, state: State}

    **collect_vpn_gateways(ec2_client, account_id, region):**
    - describe_vpn_gateways (no paginator), filter State != "deleted"
    - resource_type="vpn-gateway", resource_id=VpnGatewayId
    - ip_addresses: empty (VPN GWs don't have direct IPs, they're DDI/infra)
    - details: {vpc_attachments: list of VpcId from VpcAttachments}

    **collect_transit_gateways(ec2_client, account_id, region):**
    - Paginate describe_transit_gateways, filter State != "deleted"/"deleting"
    - resource_type="transit-gateway", resource_id=TransitGatewayId
    - details: {state: State, owner_id: OwnerId}

    Helper functions:
    - _get_name_tag(tags: list[dict]) -> str: extract Name tag value or return ""
    - _tags_to_dict(tags: list[dict]) -> dict[str, str]: convert AWS tag list to dict

    **route53.py** - Route53 is GLOBAL, not per-region. Functions take route53_client (created with region_name="us-east-1") and account_id. No region parameter -- set region="global" on CloudResource per Pitfall 1.

    **collect_route53_zones(route53_client, account_id):**
    - Paginate list_hosted_zones
    - resource_type="route53-zone", resource_id=zone Id (strip /hostedzone/ prefix)
    - name=zone Name (strip trailing dot)
    - details: {zone_type: "private" if Config.PrivateZone else "public", record_count: ResourceRecordSetCount}

    **collect_route53_records(route53_client, account_id, zone_id: str, zone_name: str):**
    - Paginate list_resource_record_sets for the given zone
    - resource_type="route53-record", resource_id=f"{zone_id}/{record_name}/{record_type}"
    - ALL record types included (A, AAAA, CNAME, MX, NS, SOA, TXT, SRV, etc.) per CONTEXT decision
    - name=record Name
    - ip_addresses: for A records, extract IP values from ResourceRecords[].Value; for AAAA, extract IPv6 values. Other types: empty ip_addresses.
    - details: {zone_id: zone_id, zone_name: zone_name, record_type: Type, ttl: TTL, alias: True/False if AliasTarget exists}

    **dhcp.py** - Takes ec2_client, account_id, region, and vpc_dhcp_ids: set[str] (set of DHCP option set IDs that are associated with at least one VPC).

    **collect_dhcp_option_sets(ec2_client, account_id, region, vpc_dhcp_ids: set[str]):**
    - Paginate describe_dhcp_options
    - resource_type="dhcp-option-set", resource_id=DhcpOptionsId
    - details: {orphaned: True if DhcpOptionsId not in vpc_dhcp_ids, configurations: list of option key-value pairs from DhcpConfigurations}
    - Per Pitfall 4: orphaned DHCP option sets (not in vpc_dhcp_ids) are still discovered but marked with details["orphaned"]=True. The categorizer (Plan 02) will set counted=False for orphaned ones.
    - To build vpc_dhcp_ids: caller (discover_account in provider.py) should first collect VPCs and extract their DhcpOptionsId values, then pass that set here. Document this dependency in a code comment.

    - Test collect_dhcp_option_sets with VPC-associated sets (orphaned=False)
    - Test collect_dhcp_option_sets with orphaned set (orphaned=True)
    - Test collect_vpcs correctly extracts DhcpOptionsId for downstream DHCP cross-reference
    - Test collect_subnets returns correct VPC association
