  <action>
In `src/cloud_usage/errors/taxonomy.py`, create:

1. `ErrorCategory` enum (using `enum.Enum`) with values:
   - `AUTH = "auth"` -- skip immediately, no retries
   - `RATE_LIMIT = "rate_limit"` -- retry with exponential backoff + jitter
   - `NETWORK = "network"` -- retry N times, then skip
   - `API = "api"` -- log and skip (e.g., unsupported region)
   - `UNKNOWN = "unknown"` -- log full traceback, skip

2. `CATEGORY_STRATEGIES` dict mapping each ErrorCategory to a dict with keys `retryable: bool`, `max_retries: int`, `description: str`:
   - AUTH: retryable=False, max_retries=0, description="Authentication/authorization failure"
   - RATE_LIMIT: retryable=True, max_retries=5, description="API rate limit exceeded"
   - NETWORK: retryable=True, max_retries=3, description="Network connectivity issue"
   - API: retryable=False, max_retries=0, description="API error (unsupported operation/region)"
   - UNKNOWN: retryable=False, max_retries=0, description="Unexpected error"

3. `ErrorRecord` dataclass with fields: `provider: str`, `account_id: str`, `category: ErrorCategory`, `message: str` (actionable user message), `raw_exception: str`, `retryable: bool`, `suggestion: str` (fix hint like "run: aws sso login"), `timestamp: str` (auto ISO timestamp).

4. `classify_error(provider: str, exc: Exception) -> ErrorCategory` function:
   - Check exception type name (lowercase) for auth keywords: "credential", "auth", "access", "forbidden", "permission" -> AUTH
   - Check exception message (lowercase) for: "accessdenied", "unauthorized", "forbidden", "403" -> AUTH
   - Check for rate limit: "429", "throttl", "rate", "too many requests", "retry-after" -> RATE_LIMIT
   - Check for network: "timeout", "connection", "socket", "dns", "resolve" in type name or message -> NETWORK
   - Check for API: "notsupported", "not found", "404", "invalid" -> API
   - Default -> UNKNOWN

5. `create_error_record(provider: str, account_id: str, exc: Exception) -> ErrorRecord` helper that calls classify_error and builds an ErrorRecord with an actionable suggestion per category (AUTH: "check that credentials are configured and not expired", RATE_LIMIT: "scan will retry automatically", NETWORK: "check network connectivity", API: "this operation may not be supported in the target region", UNKNOWN: "check the log file for full details").

In `src/cloud_usage/logging/audit.py`, create:

1. `setup_audit_logger(output_dir: str, scan_id: str | None = None) -> logging.Logger` function:
   - Creates output directory if it doesn't exist (using `pathlib.Path.mkdir(parents=True, exist_ok=True)`)
   - Generates log filename: `scan_{scan_id}_{timestamp}.log` (or `scan_{timestamp}.log` if no scan_id)
   - Creates a `logging.FileHandler` writing to that file with DEBUG level
   - Adds a `logging.Formatter` with format: `"%(asctime)s [%(levelname)s] %(name)s: %(message)s"` and datefmt `"%Y-%m-%d %H:%M:%S"`
   - Returns the configured logger
   - Also suppresses noisy third-party loggers (boto3, botocore, azure, google) to WARNING level

Per user decision in CONTEXT.md: "Every scan writes a timestamped log file to output directory automatically" and "Log file captures full debug level: all API calls, responses, timing, errors, retries" and "No redaction in logs".

3. Test classify_error returns NETWORK for timeout/connection exceptions
4. Test classify_error returns API for not-found exceptions

6. Test create_error_record builds complete ErrorRecord with correct suggestion
7. Test CATEGORY_STRATEGIES has entry for every ErrorCategory value
8. Test ErrorRecord timestamp is auto-populated

Follow project conventions: black (127 chars), Google-style docstrings, modern type hints.
